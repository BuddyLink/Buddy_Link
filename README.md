# Buddy_Link

Brief description:
BuddyLink is a mobile-first web application designed to help college students find walking companions for common campus routes. The app aims to foster both safety and social connection by matching users with nearby students walking to the same destination.  It addresses key challenges such as cultural shock, isolation ,and disorientation by offering features like buddy matching, contact sharing and notifications and identity verification.
